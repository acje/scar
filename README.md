Select and actually read applicable guidance before assessment; record exact loaded content and local policy using the template. Portable Markdown is not automatic skill-tool installation or discovery. Unsupported subjects remain Unknown without silent generic substitution.

Beads remains durable cross-agent authority for records. `.scratchpad/` is an owned, ignored workspace-local ephemeral adjunct, not a second codebase or acceptance store; `.ooda/` is unchanged. Candidate commits do not imply acceptance. The jj workflow is a specification, not a live migration: jj is unavailable on the inspected PATH and no jj runtime guarantees were tested.
