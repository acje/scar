# 13 — Two-axis skill composition

Status: existing catalogue and loading obligation; further work/profile guidance is proposed.

## Mechanism

One axis asks what to inspect: core's seven questions plus applicable audience,
security and maintainability concerns. The subject axis supplies artefact techniques:
Rust, PowerPoint, HTML and diagrams. Axes overlap, not a mathematical cross-product.

At framing select core, applicable concerns and every relevant subject profile.
Actually read complete selected guidance and binding caller policy before assessment.
Record exact path/content identity, reader/loading witness, applicability, criteria,
limits and conflicts. A configured path is not proof of actual loading.

Protocol/authority obligations and explicit task constraints govern; binding caller
style precedes provisional defaults and external advice. Missing required guidance
stays Unknown; core cannot silently stand in for unsupported subjects.

## Example

An embedded SVG explanation uses core + diagrams + HTML + audience where relevant.
Relationship inspection and actual delivered access are different evidence needs.
Rust policy does not become universal policy for a presentation.

## Limits

Eight portable Markdown units are not an installed loader. Reading and packaging
checks do not prove successful subject work. Construction/refinement subsections
and attended/unattended Rust profiles remain discussion proposals, not added skills.
Guidance changes invalidate affected criteria, conclusions and authorization.
