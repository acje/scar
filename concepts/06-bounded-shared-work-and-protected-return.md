# 06 — Bounded shared work and protected return

Status: existing SCAR accounting convention, not a production-cost model.

## Mechanism

Before substantive work declare finite positive initial work, a separate finite
positive protected return reserve, bounded operation scopes and fixed positive
heterogeneous prices. All roles and attempts share the same account.

Debit before each operation: framing, research, edits, checks, review, adjudication,
revalidation and acceptance all cost work. Failure/interruption retains the charge;
retry, role change and resume do not refund or reset it.

At 80% consumed, or before a charge reaches/crosses it, strongly signal
prepare-to-return with a bounded closure plan. This does not waive criteria.
At insufficient remaining work halt new substantive operations; a lawfully
precharged bounded operation may finish.

## Example

An executor has enough credit for a short verification but not another research
round. It chooses bounded closure rather than spending the protected return reserve
on investigation. The return records the exact scoped ordinary-Git candidate content,
any existing candidate commit IDs and introduced content, accepted base and blockers;
it does not advance main.

## Limits

Reserve funds only predeclared minimal reporting/reconciliation/accounting/upward
return from existing records, not new checks, repairs or advancement.
Continuation retains allocations and charges; extensions need explicit authorization.
The 80% signal is not a calibrated information, time or energy threshold.
