# 02 — Adaptive lifecycle

Status: existing SCAR mechanism; six documentary positions, not executable stages.

## Mechanism

1. Frame and understand intent, audience, scope, obligations and evidence context.
2. Build a coherent, significant and reviewable increment; interleave useful checks.
3. Check and assess against applicable criteria; retain results and uncertainties.
4. Resolve findings and refine with evidence-based dispositions.
5. Accept and advance main only through the designated acceptance contract.
6. Record outcome, resulting identities and continuation; select the next task.

Checks and review failures go to finding disposition, never directly to acceptance.
Repair returns to construction; broken assumptions can reopen framing within intent.
Any position can stop without acceptance and record its outcome at position 6.

## Example

A coherent document reaches assessment, which finds an unsupported source claim.
Disposition supports the finding; repair changes the claim, then refreshes review.
An unresolved required issue ends with Unresolved rather than a convenient commit.

## Limits

The positions organize adaptive work, not a mandatory form for each keystroke.
A clean assessment means no supported finding in examined content/context, not
universal truth. The lifecycle is neither a convergence proof nor runtime orchestration.
Broad understand/change/verify inspiration does not derive all six positions.
