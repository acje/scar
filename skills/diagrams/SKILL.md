# Diagrams subject profile

## Applicability
Use for explanatory graphs, charts and flow diagrams. Identify governing source, notation/legend, intended audience and delivery format; distinguish normative diagrams from explicitly supplementary illustrations.

## Techniques
1. Inventory nodes, directed edges, labels, conditions, legends and omissions; compare each consequential relationship with the governing source and record deliberate abstraction.
2. Try a reader interpretation that reverses an arrow, treats thickness/color as quantity, or infers an omitted branch is forbidden; test whether labels/context prevent it.
3. Compare short identification and structured long description with essential relationships/values/trends. Check actual delivered legibility, overlap and clipping at required outputs; use non-color cues.

## Evidence and output
Record source/diagram/export identities, node/edge or chart locators, equivalence witnesses, omission rationale and performed output/access checks. Combine HTML for embedded SVG or PowerPoint for deck delivery; map relationship checks to correctness/structure/accuracy.

## Limitations
Semantic edge comparison is a SCAR author adaptation, not a universal WAI drawing standard. No node quota, crossing count or aesthetics score. Static SVG inspection does not prove rendering/keyboard/AT/zoom/print behavior; supplementary omissions are not automatically defects. aria-describedby flattens structure and is unsuitable when structured information is necessary.
