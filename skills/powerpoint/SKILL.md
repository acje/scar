# PowerPoint subject profile

## Applicability
Use for PowerPoint decks and their delivered exports. Fix version/platform, audience, presentation context, delivery format and applicable house style before choosing checks.

## Techniques
1. Trace each slide's message and factual claim to the task/source; inspect unique slide titles and intended reading order using the platform's Reading Order or Selection Pane.
2. Review meaningful alt text (including generated text), non-color cues, contrast, simple table/header structure and legibility in the actual delivery context.
3. Run the native Accessibility Checker, then required screen-reader/presentation tests; inspect the final export separately, including captions and alternate tracks after conversion.

## Evidence and output
Record slide/object locators, deck and export identity, product/platform, observed order, native checker output, actual delivery tests and limitations. Map source claims to accuracy, message flow to structure, and access to audience concern.

## Limitations
Native checker misses some contrast cases and cannot establish task success. Microsoft font advice (including 18pt+) is context advice, not a universal SCAR threshold. Untested export/assistive technology remains Unknown; offline decks do not automatically inherit web conformance requirements.
